Baruch CS Resume Book

Fill in a spreadsheet, open it here, and save a one-page PDF in the resume-book format. Nothing to install.

Your file never leaves your computer. Everything runs inside this browser tab; nothing is uploaded or saved anywhere.
Use Google Chrome or Microsoft Edge to save your PDF. Safari and Firefox change the layout when they save a PDF, so your resume can spill onto a second page. You can check your CSV here, but open this page in Chrome or Edge to save the PDF.

2. Fill it in

Open it in Google Sheets, Excel, or Numbers.
  • Only type in the third column (Value). Each [bracketed text] says what goes there. Replace all of it, brackets included: [First Last] becomes Areeba Ikram.
  • Don't need a row or a whole section? Delete it; the template has every section, so most people delete several. Need another school, job, project, or bullet? Copy those rows and insert them right below, without pasting over the rows already there (how: see "Adding or removing a school, job, bullet, or section" below).
  • Save it as a CSV named Lastname, Firstname.csv:
    • Google Sheets: open it with File → Import → Upload, and untick "Convert text to numbers, dates, and formulas". When done, File → Download → Comma Separated Values (.csv).
    • Excel: File → Save As → CSV UTF-8.
    • Numbers: File → Export To → CSV.

Spreadsheet help (click a topic if you get stuck):

Adding or removing a school, job, bullet, or section

There are only three things you ever do to a row:

  1. Fill it in. Replace the bracketed text in Value with your own. This is most of the work.
  2. Delete it. Whatever it was for is simply left off the resume. No awards: delete all the AWARDS rows. Only two bullets for a job: delete the third Bullet row. No minor: delete the Minor row.
  3. Add one. Need a second school, job, club, project, or award? Copy all the rows of one and insert the copy directly below; there is nothing to renumber. Need another bullet? Copy a Bullet row and insert it under the others.

Inserting copied rows without overwriting the ones below. Select the rows by clicking their row numbers on the left, copy them, then:

  • Excel: right-click the row number where the copy should begin → Insert Copied Cells. The copy goes there and everything from that row on moves down. For example, to add a job at the end of Experience, right-click the first RESEARCH row.
  • Google Sheets: with the same number of rows selected, right-click → Insert rows below, then click the first new empty row and paste.
  • Numbers: with the same number of rows selected, right-click → Add Rows Below, then click the first new empty row and paste.

To delete, right-click the row number → Delete. A row left completely empty is also ignored.

Each block starts at a fixed row: a school at Institution, a job at Company, a club at Organization, an award at Award, a project at Project. Keep that row first in each block (copying a whole block does this for you). If text shows up under the wrong job, that first row is missing or out of place.

Dates, punctuation, and your name
  • Dates: Jun. 2025 - Aug. 2025, Sep. 2024 - Present, or Expected May 2027.
  • No periods at the end of bullets. No bold, italics, or bullet symbols; the generator does the formatting.
  • Write your name in Latin letters. Last name more than one word? Fill in the Last Name row (e.g. Van Der Berg) so your PDF is named correctly; otherwise delete that row.
Making a link show shorter text

LinkedIn, GitHub, Website, and a project's Website become clickable links; type them with or without https://. To show shorter text, write [GitHub repo](github.com/you/project): square brackets around the text, then the address in round brackets, with no space between. This also works inside a bullet.

Writing math on your resume

Optional, for math research. Put LaTeX between $ signs or between \( and \), e.g. Proved an $O(n \log n)$ bound. Dollar amounts like $2,000 are left alone. Keep it to a symbol or a short expression.

What you can't change (fonts, layout, section names)

You can't rename or add sections, add fields that aren't in the template, or change fonts, margins, or layout: every resume in the book has to match. If your situation needs something the format can't do, email us before submitting instead of improvising.

Fixing common problems
  • Strange characters in accented names (Ž, Ã©): the file was saved in the wrong format. In Excel choose CSV UTF-8; in Google Sheets use File → Download → Comma Separated Values.
  • "This is not a CSV file": you opened the .xlsx or .numbers file. Save or export it as a CSV first.
  • Text under the wrong job: see "Adding or removing a school, job, bullet, or section" above.
  • Brackets showing on the resume: check the link form under "Making a link show shorter text".
  • Anything else: the message on this page names the line in your file to fix.

What to write (please read)

  • Every bullet: Did X by doing Y, which resulted in Z. Use numbers where you honestly can.
    Weak: Cashier at a grocery store
    Better: Reorganized the stockroom by grouping high-turnover items near the floor, which cut restocking time by 20%
  • Stay truthful. You may be asked about anything on the page.
  • Include non-tech jobs, and list the most recent first in each section.
  • GPA: only if it is 3.4 or higher. Otherwise delete the GPA row.
  • Coursework: only courses you are comfortable being asked about, or delete the row.
  • Interests must be specific. Not "reading, chess" but "Russian literature (Dostoevsky, Gogol); chess (club tournament director)".
  • Email: use a professional address, such as your Baruch one.

Which section does it go in?

  • Experience: jobs, internships, fellowships, tutoring, teaching or course assistant work.
  • Research: only research done with a professor, lab, or institute (for example an REU). A class project is not research.
  • Publications: a paper, poster, or talk you authored at a conference, journal, or symposium.
  • Leadership: clubs, executive boards, volunteering where you had a role.
  • Projects: personal, class, and hackathon projects.

Education always prints first and Skills last; the rest print in the order they appear in your file. Move Research or Publications up if you are aiming at graduate school or research roles, or Leadership and Projects up if your jobs are all non-technical (cut the section's rows and insert them higher). Otherwise leave the order alone.

4. Save the PDF and submit

  1. Your resume opens in a new tab with the print window. Set Destination to Save as PDF and leave everything else as it is.
  2. Click Save and keep the suggested file name (Lastname, Firstname.pdf).
  3. Open the PDF and check that it is one page.
  4. Submit both files, Lastname, Firstname.pdf and Lastname, Firstname.csv, by uploading them with the Dropbox link in the email (no Dropbox account needed).
