Baruch CS Resume Book: Instructions

You fill in a spreadsheet. A script turns it into a one-page PDF in the resume-book format. Plan on 30 to 60 minutes for the writing.

What you need

  • Python 3. Check with python3 --version (Mac) or python --version (Windows). If missing, install from python.org. On Windows, tick "Add Python to PATH" in the installer.
  • Google Chrome or Microsoft Edge installed.
  • Excel, Numbers, or Google Sheets.

Before you write: what goes in a bullet

Every bullet: Did X by doing Y which resulted in Z. Be specific. Use numbers where you honestly can.

  • Weak: Worked on database optimization
  • Better: Optimized database queries by adding indexes which reduced page load time by 40%
  • Weak: Cashier at a grocery store
  • Better: Reorganized the stockroom layout by grouping high-turnover items near the floor which cut restocking time by 20%
  • Include non-tech jobs. Stay truthful: you may be asked about anything on the page.
  • Interests must be specific. Not: reading, chess. Yes: reading Russian literature (Dostoevsky, Gogol); chess (club tournament director).
  • Most recent job first.
  • Only list courses you are comfortable being asked about.
  • Use a professional email address.

Step 1: Make your own copy of the template

  1. Open one of the two templates in Excel, Numbers, or Google Sheets. They produce the same resume; pick whichever you prefer:
    • resume_template_BLANK.csv: short placeholders, less to read.
    • resume_template_GUIDED.csv: every Value spells out exactly what goes there and when to delete the row, in [square brackets]. The script refuses to finish while any brackets are left, so you cannot forget one.
  2. Save it in the same folder as the script, named with your last name, for example Chen_resume.csv:
    • Excel: File → Save As → format CSV UTF-8 (Comma delimited).
    • Numbers: File → Export To → CSV → open Advanced Options → Text Encoding Unicode (UTF-8).
    • Google Sheets: File → Import → upload the file, and untick "Convert text to numbers, dates, and formulas". When done, File → Download → Comma Separated Values (.csv), then move the download into the script's folder and rename it.

Section and Field are labels. You only type in the third column, Value. Each row is one piece of your resume: Section says which part it belongs to, Field says which piece, and Value is what it says. Replace the placeholder text in Value with your own and leave the other two columns as they are. Never change the first row.

Open example_resume.csv next to the blank template to see a finished version.

There are only three things you ever do to a row

  1. Fill it in. Replace the placeholder in Value with your own text. This is most of the work.
  2. Delete it. Don't need a row? Delete it, and whatever it was for is simply left off the resume. No awards: delete all the AWARDS rows. Only two bullets for a job: delete the third Bullet row. No minor: delete the Minor row.
  3. Add one. Need a second job, club, project, or award? Copy all the rows of the first one and paste them directly below. That's it; there is nothing to renumber. Need another bullet? Copy a Bullet row and paste it under the others.

The script knows where one job ends and the next begins because every job starts with a Company row (every school with an Institution row, every award with an Award row, every project with a Project row). So keep that row first in each block, which happens automatically when you copy a block.

RESEARCH and PUBLICATIONS are not in the blank template. To add research, copy a job block and change its Section to RESEARCH. For a publication, add the rows PUBLICATIONS,Title,..., PUBLICATIONS,Venue,..., PUBLICATIONS,Dates,....

Where things go

  • EXPERIENCE: jobs, internships, fellowships, tutoring, teaching or course assistant work.
  • RESEARCH: only research done with a professor, lab, or institute (for example an REU or a research assistant position). A class project is not research.
  • PUBLICATIONS: a paper, poster, or talk you authored at a conference, journal, or symposium.
  • LEADERSHIP: clubs, executive boards, volunteering where you had a role.
  • PROJECTS: personal, class, and hackathon projects.
  • Nothing else exists. Volunteering, competitions, teaching, and "additional experience" all go in one of the sections above.

Order on the page

Education always prints first and Skills always last. The sections in between print in the order they appear in your file: to move Research above Experience, cut its rows and paste them above the Experience rows. The default order in the template is Awards, Experience, Leadership and Projects; if you add Research or Publications, the usual place is between Experience and Leadership and Projects. When to change it:

  • Put Research or Publications before Experience if you are aiming at graduate school or research roles, or if the research is stronger than your jobs.
  • Put Leadership and Projects before Experience if your jobs are all non-technical and your projects are your best technical evidence.
  • Put Awards near the top only if they are impressive on their own.
  • Otherwise leave the order alone.

What you cannot do

  • Rename a section or invent a new one. The headings are fixed so that every resume in the book matches.
  • Add a field that is not in the table.
  • Change fonts, margins, or layout. The script does all of that.

If you think your situation needs something the format cannot do, email us before submitting instead of improvising.

Rules

  • Dates: Jun. 2025 - Aug. 2025, Sep. 2024 - Present, or Expected May 2027. If Excel changes "May 2025" to "May-25", ignore it.
  • No periods at the end of bullets. No bold, italics, or bullet symbols.
  • GPA only if 3.4 or higher. Otherwise delete the row.
  • Name in Latin letters.
  • Last name more than one word? Add a row CONTACT,Last Name,Van Der Berg so the file is named correctly.

Step 3: Run the script

Mac: open Terminal and run these two commands (drag the folder into the window to fill in the path):

cd "/path/to/CSV_VERSION"
python3 generate_resume_from_csv.py Chen_resume.csv

Windows: extract the zip first (right-click → Extract All). Then open Command Prompt and run:

cd "C:\path\to\CSV_VERSION"
python generate_resume_from_csv.py Chen_resume.csv

The last line it prints is either:

  • DONE: the PDF is one page with no warnings. It is named after you, e.g. Chen, Mei.pdf, next to your CSV.
  • NOT DONE: either the PDF ran to two pages (shorten or remove bullets) or there are WARNINGS listed above it, each naming a line in your CSV. Fix them and run the script again. Do not submit a NOT DONE resume.

An ERROR means nothing was generated; the message says what to fix.

Step 4: Check and submit

  • ☐ Name, phone, and email are correct. Links work when clicked.
  • ☐ No spelling or grammar errors. Someone else has proofread it.
  • ☐ You can talk about everything on it in an interview.

Submit both the PDF and your CSV at the link in the email. To change anything, edit the CSV and run the script again; never edit the PDF.

Troubleshooting

"command not found: python3" or "'python' is not recognized"

Windows: try py instead of python. Otherwise install Python (see What you need).

"file not found"

Your terminal is not in the folder with the CSV (see Step 3), or the file name has spaces: put it in quotes, "Mei Chen resume.csv".

"This is not a CSV file" or "The first row must be exactly: Section,Field,Value"

You saved as .xlsx or .numbers, or changed the first row. Save again as CSV (Step 1) with the first row intact.

"is not a valid field in ..." or "unknown section ... was ignored"

The Section or Field column on that line is not one of the words in the table in Step 2. Fix the spelling or move the row to the right section.

Text shows up under the wrong job, or "already has a ... value, so this row REPLACED it"

Every job must start with its Company row (school: Institution, award: Award, project: Project). Check that the block has one and that it comes first.

Strange characters in accented names (Ž, Ã©, a dash inside a word)

The file was saved in the wrong format. Save again exactly as in Step 1, choosing UTF-8.

"Font file not found"

The fonts folder must be next to the script. On Windows, extract the zip (right-click → Extract All) and run from the extracted folder.

"Chrome or Edge was not found"

The script opens the resume in your browser instead. Open that .html file in Chrome or Edge (not Safari or Firefox). The green box above the resume lists the print settings; use them to save as PDF.
